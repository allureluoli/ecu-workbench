## 没有混入公开源码包的内容

原安装程序、运行时、ASAR 及密文块、私钥、签名令牌、卡密、机器标识、真实或构造的用户工程 BIN、历史缓存日志。
旧项目导出的重复 CSV / XLSX 不再作为公开数据重复打包；同类内容可从本地库查询和导出。
项目包同时包含合成示例与完整集成库，数据许可状态见 DATA_POLICY.md。

## 可靠性边界

读取元数据与确认其修改语义是两回事。本项目可以可靠展示数据库或快照里记录的内容，但没有把来源软件的功能名称当作已验证实现。
非零 lineSkipBytes 等未确认布局只展示元数据；不会把 KP 地址直接当作 ECU BIN 偏移写回。
校验引擎可用与某个真实 ECU 校验规则被验证是两回事。目前没有 P1969 等真实 ECU 的算法支持承诺。
